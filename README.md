# Arquivo Histórico Municipal

Projeto para organização, preservação e consulta de documentos e registros históricos municipais em formato digital.

## Objetivo

Facilitar o acesso ao patrimônio documental e histórico, contribuindo para a preservação da memória do município e para a pesquisa por cidadãos, estudantes e pesquisadores.

## Possíveis recursos

- Organização de documentos por período, categoria e tema;
- Consulta de registros históricos;
- Visualização de documentos digitais;
- Estrutura preparada para pesquisa e expansão do acervo;
- Preservação e divulgação da memória municipal.
